# scripts/hackathon — 대회 후반(10/16~10/23) 일회성 스크립트

날짜는 KST 기준 파일 수정 시각이다.

대회 후반의 분석·제출은 `collector`·`pipeline` 명령 위에서 Claude Code 세션과 대화하며 진행했고, 그때 쓴 일회성 스크립트를 **실행한 그대로** 보존한다. 정리된 도구가 아니라 기록이다. 공개본에서는 제출 스크립트의 물품번호·예상액 목록(`LIST`)만 지웠다.

- 경로가 하드코딩돼 있다. `.sh`는 당시 Claude Code 세션의 임시 디렉터리(`/private/tmp/claude-501/…/scratchpad`)에 있던 목록 파일을 읽는다. 그 파일들은 저장소에 없다.
- `.py`는 `data/`(gitignore) 아래 bronze 원문·gold 후보를 읽는다. 데이터셋과 판매 페이지 원문은 재배포할 수 없어 저장소에 없으므로, 그대로는 다시 돌릴 수 없다.

| 파일 | 하는 일 | 마지막 수정 |
|---|---|---|
| `found_agg.py` | 공개 발견 카드 집계: 근거 도메인·상태(확정/보류/유보/철회)·배율·분야. 남의 링크·인용·가격은 근거로 쓰지 않고 방향만 고른다 | 10/16 |
| `found_class.py` | 발견 카드의 근거 출처 유형 분류(조달 내부·가격비교·국내 판매처·해외) | 10/16 |
| `siblings.py` | 확정된 2배 이상 카드의 (분야, 제조사)와 같은 미선점 "형제" 물품 찾기 | 10/16 |
| `ktomok_parse.py` | 토목자재 도매몰 목록 표(probe로 보관한 원문) → 품명·규격·단위·판매가·운반비 | 10/16 |
| `blocks_match2.py` | 보도블록 조달 물품 ↔ 도매몰 상품 동급 매칭(종류·두께·투수 여부·크기 ±5%) | 10/16 |
| `fill_blocks.py` | 제출 본문 초안에 동급 근거를 채운다. 인용은 보관 원문 본문에서 그대로 잘라 온다 | 10/16 |
| `submit_d3b.sh`, `submit_d3c.sh` | 사용자가 승인한 물품만 차례로 제출. 제출 직전 preview의 서버 예상액이 **승인 때 보여 준 금액과 같을 때만** 낸다 | 10/23 |
| `judge_watch2.sh` | 대회 판정기 장애 복구 감시(10분 간격). 복구되면 승인된 제출을 현재 본문으로 다시 올려 재검사를 받는다 | 10/23 |

## 알려진 차이
- `fill_blocks.py`는 **첫 버전**이다. 비교 단가에 판매처가 적은 운반비 예상액을 더한다. 10/16~10/19에 처음 낸 블록 28건이 이 버전이고, 10/19에 대회 「자료와 방법」 2절(배송비는 더하지 않는다)에 맞춰 28건 모두 운반비를 뺀 수정(revision 2)을 올렸다. 그 수정에 쓴 스크립트는 남아 있지 않다(세션 안에서 직접 고쳤다).
- 벤치플룸관·옹벽 블록·그레이팅 덮개 본문(`data/gold/claims_new/`)을 만든 스크립트도 남아 있지 않다.
