## 규칙 핵심
- 대상: 조달 쇼핑몰 상품 전체(등재 약 105만 건, 물품번호 약 99만 개). 같은 상품인지는 **물품번호가 같은지**로 판단한다.
- 등록: 물품번호로 상품을 열고, 싼 가격과 근거(판매 페이지 링크 + 그 페이지 내용을 옮겨 적은 인용 글)를 제출한다. 파일 업로드는 쓰지 않는다.
- **선착순:** 같은 상품은 가장 먼저 등록한 한 사람만 가진다. 개혁신당이 먼저 찾은 상품은 등록할 수 없다.
- 가격 차이 기준: 납품 단가 ≥ 시중가 × 1.2 **또는** 단가 차이 ≥ 1,000,000원(둘 중 하나). 여러 줄이면 시중가보다 비싼 줄만 모아 단위별로 수량 가중 평균을 낸다.
- 금지: 남이 올린 근거를 내 조사처럼 올리기, 개인·기관을 잘못했다고 단정하기. 공개 내용을 참고해 새 상품을 분석하는 것은 허용된다.
- 에이전트·스크립트 참가 허용(브라우저와 같은 개인 한도 사용).
- 제출 즉시 상품·비교 가격·근거·예상액이 다른 참가자에게 공개된다.
- 반증: 남의 제출에 이상하다는 의견을 남길 수 있다(점수는 바로 바뀌지 않고, 마감 후 확인할 때 참고).
- 운영진 반려: 물품이 다시 열리고 등록 기회 1회를 돌려받는다.
- 마감 후: 근거 재확인 → 이의 기간 → 확정 금액으로 최종 순위. **확정 금액은 예상액보다 커지지 않는다.**

## 상금 규정
- 총상금 세전 1,000만 원, 개혁신당 중앙당 명의로 지급, 원천징수 후 지급.
- 산정액 = 1,000만 × (내 확정 금액 ÷ 시상 대상자 전원의 확정 금액 합계).
- 1,000원 미만은 버린다. 기본 상금이 10,000원 미만이면 지급하지 않는다(1위 제외). 잔액은 1위에게 더한다.
- 제외 대상: 이준석 의원, 주최자·플랫폼 운영 관계자, 실격·수상 취소자.
- 지급: 실명·계좌 명의 확인 후 **본인 명의 계좌**로 지급. 확정 공지 후 90일 안에 지급 정보를 내지 않으면 지급하지 않을 수 있다.
- 공지 후 7일 안에 재검토를 요청할 수 있다. 1인 다계정은 약관 제10조로 처리.
- 참가·수상은 당원 가입·후원·지지와 연계하지 않는다(제11항).
- 확인 필요: 해외 거주자가 받을 수 있는지(한국 계좌 필요 여부)는 데이터 이용 약관(#/terms)에서 직접 확인한다.

## 전략 메모
1. **기준선은 데이터셋.** API 한도(3,600회/시간) 때문에 전체를 API로 훑을 수 없다. 데이터셋으로 후보를 뽑고 API는 검증에만 쓴다.
2. **선점 확인을 일찍, 자주.** 후보를 만들면 바로 `items/lookup`(100개씩, 무료)으로 걸러낸다. 제출 직전에 한 번 더 확인한다.
3. **철회·반려로 풀리는 물품을 노린다.** `watch`로 피드에서 `delta_krw < 0`(철회)과 반려를 감지하면 즉시 lookup한다(`release_claim_on_withdraw=true`).
4. **수량이 큰 물품 우선.** 예상액 = C − B×Q이므로 단가 차이보다 총 납품 금액 C가 큰 물품이 유리하다.
5. **검증에서 살아남는 근거.** 동일 모델·동일 포장 단위·동일 세금 기준. 정적 HTML 판매 페이지. quote에 모델·가격·VAT·배송·판매처·날짜를 모두 적는다.
6. **suspect 즉시 수정.** 보류 금액은 순위 합계에서 빠진다. lint 사유를 읽고 revision으로 고친다.
7. **제출 한도 관리.** 철회해도 횟수는 돌아오지 않는다. 확신도가 높은 후보만 제출한다.
